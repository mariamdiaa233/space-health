# Space Health — HTML, CSS, JavaScript

واجهة ويب تجريبية عربية ومتجاوبة.

## التشغيل محليًا
1. فك ضغط الملف.
2. افتح `index.html` في Chrome أو Edge.
3. لا تحتاج إلى تثبيت Flutter أو Android Studio.

## رفعه على GitHub Pages
1. سجّل الدخول إلى https://github.com
2. اضغط New repository، واكتب `space-health`، واختر Public، ثم Create repository.
3. من المستودع اضغط Add file ثم Upload files.
4. ارفع الملفات الثلاثة مباشرة إلى جذر المستودع: `index.html` و`style.css` و`script.js` (لا ترفع ZIP فقط).
5. اضغط Commit changes.
6. افتح Settings ثم Pages.
7. تحت Build and deployment اختر Deploy from a branch.
8. اختر Branch: `main` والمجلد `/ (root)` ثم Save.
9. انتظر اكتمال النشر، ثم افتح الرابط الظاهر في صفحة Pages. غالبًا يكون:
   `https://YOUR-USERNAME.github.io/space-health/`

## تنبيه
هذه واجهة Front-end فقط. القيم المعروضة افتراضية، ولا يوجد اتصال فعلي بمستشعرات أو Bluetooth أو نظام طبي. لا تستخدم لاتخاذ قرارات صحية.
